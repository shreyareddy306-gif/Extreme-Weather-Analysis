🌦️ Extreme Weather Analysis

📌 Project Overview

Extreme Weather Analysis is a data analysis project that explores weather conditions and extreme weather events using Python and Power BI.

The project analyzes weather data to identify patterns and visualize important weather metrics.

🎯 Objectives

- Analyze weather data using Python.
- Explore monthly temperature and wind speed patterns.
- Examine heatwave and cold snap occurrences.
- Create interactive visualizations using Power BI.

🛠️ Tools and Technologies

- Python
- Google Colab
- Pandas
- Matplotlib
- Power BI
- SQLite

📂 Project Files

- "weather_analysis.ipynb" – Notebook containing weather data analysis.
- "Weather.db" – Weather database.
- "daily_weather_clean.csv" – Cleaned weather dataset.
- "dashboard_weather_analysis.pbix" – Power BI dashboard.
- "README.md" – Project documentation.

📊 Dashboard

The Power BI dashboard includes:

- Maximum and minimum temperature metrics.
- Monthly temperature trends.
- Average wind speed by month.
- Heatwave and cold snap visualizations.
- Extreme weather day count.

🔍 Key Analysis

Data Cleaning

- Loaded weather data from SQLite into Pandas.
- Handled missing values and placeholder values.
- Removed invalid records.
- Standardized date formats.

Exploratory Data Analysis (EDA)

- Generated summary statistics.
- Visualized daily and monthly weather patterns.
- Created histograms and boxplots.
- Examined temperature, precipitation, and wind speed.

Extreme Weather Detection

- Heatwave: Maximum temperature above 90°F.
- Cold snap: Minimum temperature below 32°F.
- High wind: Wind speed above 20 mph.
- Heavy rain: Precipitation above 1 inch.

📈 Results and Insights

- Heatwaves were concentrated in July and August.
- Cold snaps occurred mainly in January and February.
- Heavy rainfall was less frequent, with some significant spikes in fall.

🚀 How to Run

1. Open "weather_analysis.ipynb" in Google Colab.
2. Upload or connect the required weather dataset.
3. Run the notebook cells in order.
4. Explore the analysis and visualizations.
5. Open the Power BI dashboard using Power BI Desktop.
